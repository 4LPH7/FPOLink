# Meta WhatsApp Cloud API — Production Setup Checklist

> **Target Audience:** DevOps, System Administrators, and FPO Project Leads.  
> **Project:** FPOLink (FastAPI + PostgreSQL + Docker WhatsApp Cloud API Integration).  
> **Scope:** Step-by-step human runbook for taking the FPOLink WhatsApp bot live on Meta's official WhatsApp Business Cloud API in production.

---

## Prerequisites

Before beginning this checklist, gather the following prerequisites:

- [ ] **Legal Entity Documents (FPO / FPC):**
  - Certificate of Incorporation (under the Companies Act) or Registration Certificate (under the Tamil Nadu Cooperative Societies Act) for the Farmer Producer Organisation.
  - Permanent Account Number (PAN) card of the FPO entity.
  - Goods and Services Tax (GST) registration certificate or Udyam / MSME registration certificate (if applicable).
- [ ] **Proof of Address:**
  - Recent utility bill (electricity, water, landline) or official bank statement in the exact legal name and registered address of the FPO (issued within the last 3 months).
- [ ] **Dedicated Phone Number (SIM):**
  - A dedicated physical SIM or eSIM card with an active voice/SMS plan capable of receiving OTPs in India (+91).
  - **CRITICAL:** This number must **NOT** be currently registered or active on standard WhatsApp or WhatsApp Business mobile apps. If it is currently active, the WhatsApp account must be permanently deleted inside the mobile app (`Settings > Account > Delete my account`) before proceeding.
- [ ] **Domain & Public HTTPS Endpoint:**
  - A registered domain or subdomain (e.g. `api.yourdomain.com`).
  - Publicly accessible HTTPS endpoint pointing to the FPOLink backend service (e.g. via Cloudflare Tunnel or reverse proxy with valid TLS/SSL certificate).
- [ ] **Meta Administrator Profile:**
  - A personal Facebook account in good standing with 2-Factor Authentication (2FA) enabled, which will act as the primary administrator for Meta Business Suite.
- [ ] **Payment Method:**
  - Corporate or business credit/debit card enabled for international transactions and recurring e-mandates (required by Meta for business messaging billing).
- [ ] **Server Access:**
  - SSH access to the production host with permissions to update the [.env](file:///d:/PROJECTS/FPOLink/.env) file and restart Docker containers.

## Environment Variables Reference

The following environment variables in FPOLink configure the WhatsApp Cloud API integration (defined in [app/config.py](file:///d:/PROJECTS/FPOLink/backend/app/config.py)):

| Variable | Description | Source in Meta Console | Example Format |
|---|---|---|---|
| `WHATSAPP_ENABLED` | Master kill switch for all WhatsApp features | Local configuration | `true` |
| `WHATSAPP_VERIFY_TOKEN` | Secret token string chosen by you for the webhook handshake | Generated by you; entered into Meta Webhook config | `fpo_webhook_verify_7f9a2b4...` |
| `WHATSAPP_APP_SECRET` | Secret key used to verify incoming HMAC SHA-256 signatures | App Dashboard > App settings > Basic > App Secret | `3c8d1e...` |
| `WHATSAPP_ACCESS_TOKEN` | Permanent System User access token with messaging permissions | Business Settings > Users > System Users > Generate Token | `EAAB...` (long string) |
| `WHATSAPP_PHONE_NUMBER_ID` | Meta's internal ID for the registered WhatsApp phone number | WhatsApp Manager > Account tools > Phone numbers | `109283746591024` |
| `WHATSAPP_BOT_PHONE` | Registered phone number with country code (digits only) | The physical SIM number | `919876543210` |
| `WHATSAPP_API_VERSION` | Supported Graph API version | Meta Graph API documentation | `v23.0` |

> [!WARNING]
> When `ENVIRONMENT=production`, FPOLink enforces strict startup validation: if `WHATSAPP_ENABLED=true`, the application will refuse to start if any of `WHATSAPP_VERIFY_TOKEN`, `WHATSAPP_APP_SECRET`, `WHATSAPP_ACCESS_TOKEN`, or `WHATSAPP_PHONE_NUMBER_ID` are missing.

## Step-by-Step Production Runbook

### Step 1: Create Meta Business Account

- [ ] 1.1. Navigate to [Meta Business Suite](https://business.facebook.com).
- [ ] 1.2. Click **Create an account** (or log in with your primary administrative Facebook profile).
- [ ] 1.3. Enter your business name (use the official legal name of the Farmer Producer Organisation, e.g., `Erode Organic Farmers Producer Company Ltd`), your full name, and your official business email address.
- [ ] 1.4. Check your email inbox to verify the business email address.
- [ ] 1.5. Go to **Business Settings > Users > People** and invite at least one secondary administrator to ensure organizational redundancy.

---

### Step 2: Create Meta Developer App

- [ ] 2.1. Navigate to the [Meta for Developers Portal](https://developers.facebook.com).
- [ ] 2.2. Log in with your Meta account and click **My Apps** in the top-right navigation bar.
- [ ] 2.3. Click **Create App**.
- [ ] 2.4. Select **Other** as the use case (or **Business** type if prompted for app type), and click **Next**.
- [ ] 2.5. Select **Business** as the app type and click **Next**.
- [ ] 2.6. Configure app details:
  - **App Name:** Enter a recognizable name (e.g., `FPOLink Production API`).
  - **App Contact Email:** Enter the technical contact email.
  - **Business Account:** Select the Meta Business Account created in Step 1.
  - Click **Create App** and complete the security reCAPTCHA / password challenge.
- [ ] 2.7. On the **Add products to your app** dashboard, locate the **WhatsApp** tile and click **Set up**.
- [ ] 2.8. Note your **App ID** and retrieve your **App Secret** from **App settings > Basic > App Secret**. Save this value as `WHATSAPP_APP_SECRET` in your `.env`.

### Step 3: Business Verification

> [!IMPORTANT]
> Business verification is mandatory to lift messaging limits beyond the unverified tier (250 conversations/24h) and to scale up to Tier 1 (1,000 unique recipients/day) and Tier 2 (10,000 recipients/day). Typical verification timeline is **2 to 7 business days**.

- [ ] 3.1. Go directly to Meta Business Settings Security Center: [https://business.facebook.com/settings/security](https://business.facebook.com/settings/security).
- [ ] 3.2. Under **Business Verification**, click **Start Verification**.
- [ ] 3.3. Enter official legal business details:
  - **Legal Business Name:** Must match your incorporation documents exactly.
  - **Address:** Must match the proof of address document exactly.
  - **Phone Number & Website:** Provide the official organizational website (e.g. `https://fpolink.in`).
- [ ] 3.4. Upload verification documents:
  - **Document 1 (Legal Existence):** FPO Certificate of Incorporation / Society Registration + PAN Card.
  - **Document 2 (Address Proof):** Recent electricity bill, landline bill, or formal bank statement showing the entity's address.
- [ ] 3.5. Select a verification contact method:
  - **Email:** Verification code sent to an email matching your domain (e.g., `admin@fpolink.in`).
  - **Domain Verification:** DNS TXT record added to your domain registrar (recommended for fastest approval).
- [ ] 3.6. Submit the verification request and monitor status daily in the Security Center.

### Step 4: Phone Number Registration

> [!CAUTION]
> The phone number must be a dedicated SIM. It cannot be used on a mobile phone with the WhatsApp consumer or WhatsApp Business app once onboarded to the Cloud API.

- [ ] 4.1. Navigate to **WhatsApp Manager**:
  - In Meta Developer Portal: Click **WhatsApp > API Setup** in the left sidebar, or open [WhatsApp Manager](https://business.facebook.com/wa/manage/phone-numbers/).
- [ ] 4.2. Go to **Account tools > Phone numbers** and click **Add phone number**.
- [ ] 4.3. Enter display information:
  - **WhatsApp Business Display Name:** E.g., `FPOLink Erode Advisory` (must comply with Meta Display Name guidelines and clearly represent the FPO).
  - **Category:** Select **Public Service**, **Agriculture**, or **Non-Profit**.
  - **Business Description:** Brief summary (e.g., `Official market price updates and farmer advisory service for Tamil Nadu FPOs`).
- [ ] 4.4. Enter the phone number with country code `+91` (India).
- [ ] 4.5. Select **Text message (SMS)** or **Voice call** to receive the 6-digit one-time verification code (OTP).
- [ ] 4.6. Enter the OTP in Meta console to confirm ownership.
- [ ] 4.7. After registration completes, locate your phone number in the Phone Numbers table:
  - Copy the **Phone Number ID** (e.g. `109283746591024`). Set this as `WHATSAPP_PHONE_NUMBER_ID` in `.env`.
  - Record the phone digits with country code (e.g. `919876543210`). Set this as `WHATSAPP_BOT_PHONE` in `.env`.

### Step 5: System User Token Generation

> [!NOTE]
> Temporary tokens generated on the Developer App dashboard expire after 24 hours. Production services require a permanent System User token that does not expire.

- [ ] 5.1. Open [Business Settings > Users > System Users](https://business.facebook.com/settings/system-users).
- [ ] 5.2. Click **Add** to create a new System User:
  - **System Username:** `fpolink-bot-service`
  - **System User Role:** `Admin`
  - Click **Create System User**.
- [ ] 5.3. Assign assets to the System User:
  - Click **Add Assets** for `fpolink-bot-service`.
  - Under **Apps**, select your Developer App (`FPOLink Production API`) and enable **Full control (Manage App)**.
  - Under **WhatsApp Accounts**, select your WhatsApp Business Account and enable **Full control (Manage WhatsApp Business Account)**.
  - Click **Save Changes**.
- [ ] 5.4. Generate the permanent token:
  - Click **Generate New Token**.
  - Select your App from the dropdown.
  - **Token expiration:** Select **Never**.
  - Check the following two required permissions:
    - [x] `whatsapp_business_messaging` (send and receive WhatsApp messages)
    - [x] `whatsapp_business_management` (manage WhatsApp settings and templates)
  - Click **Generate Token**.
- [ ] 5.5. **Copy the token immediately** and store it securely. Meta will never display it again.
- [ ] 5.6. Save this token as `WHATSAPP_ACCESS_TOKEN` in your production `.env`.

### Step 6: Message Template Submission

FPOLink relies on pre-approved Meta message templates for outbound broadcasts:
1. `daily_price_digest` — Sent daily at 07:30 IST to opted-in farmers (handled by [DailyDigestService](file:///d:/PROJECTS/FPOLink/backend/app/services/whatsapp_digest.py)).
2. `price_move_alert` — Sent daily at 07:45 IST when price fluctuations $\ge 5\%$ occur (handled by [PriceMoveAlertService](file:///d:/PROJECTS/FPOLink/backend/app/services/whatsapp_alerts.py)).

> [!WARNING]
> **Cost Control Advisory:** Meta classifies messages into **Utility**, **Authentication**, **Service**, and **Marketing**.
> - **Utility messages** (India rate): approx. **₹0.35** per conversation.
> - **Marketing messages** (India rate): approx. **₹0.85** per conversation (more than double).
> Always submit the price digest as **Utility**. Use strictly factual, transactional language (crop name, price, market, date). **Avoid any promotional text, emojis, discounts, sales offers, or calls to action**, or Meta's automated classifiers will reject or reclassify your template into Marketing.

- [ ] 6.1. Go to [WhatsApp Manager > Account tools > Message templates](https://business.facebook.com/wa/manage/message-templates/).
- [ ] 6.2. Click **Create Template**.
- [ ] 6.3. Configure the `daily_price_digest` template:
  - **Category:** `UTILITY`
  - **Template Name:** `daily_price_digest`
  - **Languages:** Add **Tamil (ta)** and **English (en)**.

#### Template Specifications for `daily_price_digest`

##### Tamil (`ta`) Template:
- **Body Text:**
  ```text
  வணக்கம். இன்றைய சந்தை மாதிரி விலை நிலவரம்:
  பயிர்: {{1}}
  மாதிரி விலை: ₹{{2}}/குவிண்டால்
  சந்தை: {{3}}
  FPOLink உழவர் தகவல் சேவை.
  ```
- **Sample Values for Approval Review:**
  - `{{1}}`: `மஞ்சள்`
  - `{{2}}`: `7200`
  - `{{3}}`: `ஈரோடு`

##### English (`en`) Template:
- **Body Text:**
  ```text
  Hello. Today's market modal price update:
  Crop: {{1}}
  Modal Price: ₹{{2}}/quintal
  Market: {{3}}
  FPOLink Farmer Advisory Service.
  ```
- **Sample Values for Approval Review:**
  - `{{1}}`: `Turmeric`
  - `{{2}}`: `7200`
  - `{{3}}`: `Erode`

#### Optional: Template Specification for `price_move_alert`
- **Category:** `UTILITY`
- **Template Name:** `price_move_alert`
- **Languages:** Tamil (`ta`) & English (`en`)
- **Body Text (Tamil):**
  ```text
  முக்கிய விலை நிலவர அறிவிப்பு:
  பயிர்: {{1}} விலை {{2}} ({{3}}).
  தற்போதைய மாதிரி விலை: ₹{{4}}/குவிண்டால்.
  சந்தை: {{5}}.
  ```
  *(Sample values: {{1}}=மஞ்சள், {{2}}=உயர்வு, {{3}}=6.5%, {{4}}=7600, {{5}}=ஈரோடு)*

- [ ] 6.4. Submit both templates for review. Approval typically takes from **5 minutes to 24 hours**. Check status in WhatsApp Manager until marked **Approved** (Green).

### Step 8: Webhook Configuration

- [ ] 8.1. Generate a strong, cryptographically random verification string on your local machine:
  ```bash
  openssl rand -hex 24
  ```
  Set this value as `WHATSAPP_VERIFY_TOKEN` in your server's `.env`.
- [ ] 8.2. Ensure the FPOLink backend is running and reachable at your domain:
  - Local endpoint: `http://localhost:8000/api/whatsapp/webhook`
  - Public route: `https://api.yourdomain.com/api/whatsapp/webhook`
- [ ] 8.3. Go to Meta Developer Dashboard:
  - Navigate to **WhatsApp > Configuration**.
  - In the **Webhook** section, click **Edit**.
- [ ] 8.4. Enter the Webhook parameters:
  - **Callback URL:** `https://api.yourdomain.com/api/whatsapp/webhook`
  - **Verify Token:** Enter the exact string generated in Step 8.1 (`WHATSAPP_VERIFY_TOKEN`).
- [ ] 8.5. Click **Verify and Save**. Meta will send an HTTP `GET` request with challenge parameters. The FPOLink backend will return the challenge code with HTTP 200.
- [ ] 8.6. In the **Webhook fields** section below the URL configuration:
  - Find `messages` and click **Subscribe**.
  - *(Optional)* Subscribe to `message_template_status_update` to track template approvals.
- [ ] 8.7. Send a test WhatsApp message from a personal phone to your registered bot phone number. Inspect backend logs:
  ```bash
  docker compose logs --tail=50 backend
  ```
  Verify that an inbound message webhook arrives and is processed with HTTP 200.

### Step 9: Quality Rating Monitoring

Meta actively monitors user sentiment and blocks/spam reports to assign a phone number **Quality Rating**.

- [ ] 9.1. Regularly inspect phone health in [WhatsApp Manager > Account tools > Phone numbers](https://business.facebook.com/wa/manage/phone-numbers/):
  - **Green (High):** Normal operational state.
  - **Yellow (Medium):** Warning state. Farmers may be blocking messages or marking them as spam.
  - **Red (Low):** Critical state. Meta may reduce your 24-hour messaging limit tier (e.g. from 10k down to 1k or 250).
  - **Flagged:** The number is in a 7-day probation period. If quality does not recover, messaging limits decrease permanently.
- [ ] 9.2. Best practices to maintain High quality:
  - **Explicit Opt-in:** Only send proactive digests to farmers who have registered and requested alerts (`Farmer.alerts_opt_in = True`).
  - **Instant Opt-out:** Honour unsubscriptions (`ALERTS OFF` / `STOP`) immediately with zero grace delay.
  - **Freshness Gate:** Never send stale price updates (enforced by FPOLink's `is_price_stale` check).
  - **Frequency Cap:** FPOLink strictly enforces a maximum of 1 digest and 1 alert per farmer per day.
- [ ] 9.3. If quality drops or the number is mistakenly flagged:
  - Review recent unsubscriptions or error rates in the database `outbound_messages` table.
  - Open a support ticket via [Meta Business Support](https://business.facebook.com/bsp/support) with proof of opt-in consent from the FPO membership records.
